How this line runs

Model

A scikit‑learn Pipeline: median/mode imputation → standard scaling for numeric fields and one‑hot encoding for borough & neighbourhood → a Random Forest classifier (200 trees, class‑balanced) on top.

Training data

NYC Airbnb open listings — 10 features per row: coordinates, price, minimum nights, review volume & pace, host listing count, yearly availability, and location.

Output

One of three room types — Entire home/apt, Private room, Shared room — plus the full probability spread the forest voted across all three.

Serving

A local FastAPI app loads the pickled pipeline once at startup and exposes it at POST /predict. This page is a plain static client — CORS is open, no build step needed.

Heads up — this reads listing metadata, not photos or descriptions, so odd combinations (e.g. a $2,000/night shared room) will still get a confident‑looking guess. Treat it as a signal, not a verdict.
